# Reglas del negocio
Un grupo de docentes y estudiantes de la carrera de medicina de la Unifranz, realiza visitas medicas a comunidades rurales del departamento 
de La Paz, con el objetivo de brindar atencion medica a los habitantes de dichas comunidades, ademas de obtener datos estadisticos sobre las
patologias mas comunes en dichas comunidades, para futuras investigaciones.

Para cada visita, un docente investigador, denominado Jefe del viaje, en conjunto con 2 docentes de tiempo completo, denominados organizadores,
planean el viaje y se organizan las siguientes 9 estaciones:

    - Anamnesis (Entrevista con el paciente para obtener un historial familiar, datos previos, etc)
    - Examen fisico general (Signos vitales)
    - Examen fisico segmentario (Examen de cada parte del cuerpo)
    - Scrining (Glicemia capilar, grupo sanguineo, EGO) (Examenes de laboratorio)
    - Diagnostico Clinico / Farmacia
    - Electrocardiograma
    - Espirometria
    - Ecografia
    - Recoleccion de datos (realizada por los guias)

Cada estacion estara a cargo de un docente y cuatro estudiantes, y es espera que un paciente pase por todas las estaciones, para que una
historia clinica completa sea registrada, sin embargo, un paciente puede ser enviado desde una estacion hasta cualquier otra.

Se debe usar el estandar CIE para el registro de enfermedades, y se debe tener un stock de medicamentos, para poder emitir reportes 
para las autoridades de la comunidad.

# Para el registro de insumos

para tener un control de insumos rotos, perdidos, en mal estado o incluso si fueron usados o adquiridos.

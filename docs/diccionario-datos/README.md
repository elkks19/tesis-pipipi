# Diccionario de datos separado por entidad

Formato: cada archivo empieza con el nombre de la entidad como texto plano y luego incluye una tabla `.tsv` separada por tabulaciones. Son adecuados para copiar y pegar en Word o Excel.

- [Examen físico segmentario](examen_fisico_segmentario.tsv)
- [Laboratorios](laboratorios.tsv)

Para Word: copiar el nombre de la entidad como título y luego copiar la tabla. Si la tabla no aparece automáticamente, seleccionar solo las filas tabuladas y usar **Insertar > Tabla > Convertir texto en tabla** con separador **Tabulaciones**.
